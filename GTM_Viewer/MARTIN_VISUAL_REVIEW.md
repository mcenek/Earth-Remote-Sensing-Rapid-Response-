# Visual review of saved methane predictions

From a fresh clone on Windows, double-click `GTM_Model0_OpenViewer.cmd` at the repository root. On other systems, run `python tools/GTM_Model0_local_viewer.py --open` from the repository root. Open `http://127.0.0.1:8766/` if the browser does not open automatically. Python 3.11 or newer is sufficient for the viewer; no model weights, data download, inference, or package installation is needed.

The **Experiment** menu automatically includes two portable samples. Select **Model6 mapper r5 | mean | development | portable visual sample** to review five MARS scenes: all three reviewed plume scenes, the no-plume scene with the most native false-positive pixels, and an early no-plume control. Select **Model6 | Evidence constrained | mean | portable visual sample** to review three dated EMIT positive outlines. Use **Plume comparison** for aligned Sentinel imagery, actual saved prediction probability or thresholded mask, and the reference outline. Toggle **Disagreement**, switch to **Side by side**, move the threshold, and hover a pixel to check the values. The default threshold is the saved 0.50 decision cutoff. Threshold changes affect only the visual display scores.

These scenes were chosen for diagnostic contrast. They do **not** estimate overall performance. The R5 run failed its quality gate: its complete 65-scene reused development fold had 2.15% pooled native IoU and 2.25% precision. The selected localized success does not cancel its misses and background false positives. R5 uses reviewed MARS masks, not a quantitative EMIT methane surface. The separate EMIT examples show catalog **positive support only**; outside the outline is unknown, so false-positive rate, precision, and IoU against independent methane truth cannot be inferred there. Neither run establishes a reliable US methane map or verified emission origins.

The portable assets are under `GTM_Viewer/portable_bundles/` and load without the ignored `outputs/` directory. The full local runs, if present, remain in the Experiment menu separately. This viewer uses local imagery and scripts; leave **Online basemap** off to avoid optional map tile requests.

The bundle file hashes are in `portable_bundles/SHA256SUMS.txt`. A [repeatable viewer check](../reports/research/GTM_Model6_portable_viewer_verification_2026-09-25.md) records the expected on-screen results.
