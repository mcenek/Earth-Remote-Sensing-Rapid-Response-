# Expanded-fit external evaluation, before inference

Joshua authorized retraining both models and viewing predictions on real plume and no-plume scenes. Preserve the fixed training and DEV rules in `GTM_Model7_diversity_comparison_protocol_20261024.md`. This document defines an additional, bounded, inspection-only external check before any new inference result is read.

## Failures to prevent

1. A fitting scene, its reference, a nearby date, or a nearby physical site becomes an external case. Use a separate manifest. Exclude combined-cohort IDs, target/reference acquisition IDs, spectral hashes, matching physical locations, and all sites within 25 km of any combined-cohort scene. Source reference observations are subject to the same exclusions. Use existing metadata and source hashes before choosing cases.
2. Historical project exposure is concealed. Audit existing project manifests by identifiers and sites. Distinguish unseen by the new weights from project-untouched. If historical exposure cannot be ruled out, disclose that limitation. The old Kansas/Mississippi evaluation is already reviewed; do not call it fresh.
3. Label shape or prediction quality chooses evaluation examples. Select candidate IDs deterministically from metadata before reading their pixel labels or model outputs. Prefer cached official validation/test sites outside the full combined cohort. Country and physical-site round-robin, at most 10 positive sites, at most two positive observations per site and four no-plume observations per site, aiming for both classes. Fix selected IDs and source roles in an audit manifest first. Do not fill failing QA slots based on results. Record exclusions and empty quotas.
4. Landsat, L2A or continuous EMIT data silently enter this six-band L1C task. Accept Sentinel-2 L1C MARS sources only, exact delivered grid and B02/B03/B04/B08/B11/B12 semantics. Use released binary plume annotations and explicit source NO_PLUME classes, not missing labels or CAFO appearances.
5. A fake clear reference or poor source contract enters inference. References must be actual earlier same-site, same-grid NO_PLUME observations, at least 24 hours and at most 60 days earlier. Verify upstream hashes, band/grid/dtype contracts, both dates' own cloud masks, positive finite support, frozen snow-like rule and at least 90% two-date valid support, as for the training export. Save attempts and reasons. Choose nearest passing eligible reference by time then ID, without using label geometry or methane contrast. No normalization is fit on external data.
6. Evaluation changes the model. Strict DEV-only selection freezes each checkpoint, train normalization and cutoff before external inference. Preserve those choices even if the external check fails. Existing DEV gates remain unchanged. The user requested visual testing, so even a failed DEV candidate may be shown externally as a diagnostic with its failure label. This does not promote a failed candidate or authorize tuning on this collection.
7. A visually attractive subset hides failure. Save scores, valid support, native confusion counts and overlays for every accepted external observation from both models, including empty masks and false alarms. Report pooled and per-site metrics, clear-pixel false positives and clear scenes activated, along with all-positive/all-negative controls. Scores are not calibrated probabilities; repeated 20 m outputs are not learned 10 m upscaling.
8. A display error becomes a scientific result. Independently reconstruct every input, annotation and validity mask from original sources. Replay frozen predictions in a separate process and independently recount native support. The root agent inspects the actual figures and live viewer, switches positive/negative scenes, models, overlays/errors/scores and verifies source dates/cutoffs. Save E2E receipts and a browser screenshot.

No imagery downloads are required. Stop if source contracts, independence or runtime limits fail; preserve evidence. An international external check does not establish national US performance. Do not expand to statewide inference or change thresholds after this check.
