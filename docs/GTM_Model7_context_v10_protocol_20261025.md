# Deeper spatial context trial and useful-score target

Written before implementation, fitting or new candidate predictions. Follow-up to v9 on October 25, 2026.

## Question and target

The small two-pool U-Net still misses real plumes in TRAIN as well as DEV. V8 TRAIN pooled native IoU at cutoff 0.50 is about 0.334, 0.400, 0.430 and 0.429 at the four milestones. V9 peaks at 0.463. More updates did not consistently improve DEV. Equal scene overlap loss did not solve the problem. Capacity and spatial context are plausible limits, not established causes.

Test one deeper residual early-fusion U-Net. Keep preprocessing, loss, data and sampling fixed to v8. Do not enlarge masks, use label-shaped crops for inference, fill blobs, apply dilation, choose only successful images, or call background accuracy a useful metric.

The user requests a useful metric above 70%. Fix the target now: pooled native plume F1 at least 0.70 on all 198 DEV observations, including false positives in clear scenes. F1 = 2TP/(2TP+FP+FN). Do not use a per-scene success or precision-only score in its place.

For the result to be a useful development candidate, also require precision at least 0.70, recall at least 0.65, mean positive-site recall at least 0.50, at least 23 of 46 positive observations recovering half their labeled pixels, clear false-positive pixels no more than selected v7's 5,140, and no more than 20 of 152 clear observations with any positive pixel. These are prospective study gates, not a claim that they establish national readiness. A result below these gates must be reported as such. No guarantee that this trial reaches the target.

## One controlled fit

- New architecture: residual encoder/decoder blocks with widths 24, 48, 96, 192; three average-pooling stages; bilinear upsampling to the exact skip grid. Each block: 3x3 convolution, GroupNorm with four groups, SiLU, 3x3 convolution, GroupNorm with four groups, plus a 1x1 linear shortcut if widths differ, then SiLU. Decoder concatenates the corresponding skip. One linear 1x1 output head. No dropout, attention, new loss or pretrained download. The 100x100 input therefore follows 100,50,25,12 spatial stages. This tests the complete architecture change, not an isolated depth or width effect.
- Same 24 channels: six current bands, six reference bands, signed and absolute differences from the frozen date-median-centered log preprocessing. Same TRAIN-only normalizer. Output stays 100x100 at 20 m; nearest repeat on the 200x200 annotation grid for native measurement. No learned 10 m upscaling claim.
- Same fixed combined manifest SHA 1f08f7cf0d0a610044b58a5de9eaff1b708359fd4d06cf8a88a00bc43708c63a: 958 TRAIN observations, 268 positive and 690 clear; 198 exposed DEV observations, 46 positive and 152 clear. No final arrays. Source array hashes and label/support conventions must remain unchanged. No changes to old manifests, trainers, recipes or receipts.
- Same exact v8 draw schedule: 4,800 updates, four plume and four clear observations per batch, uniform physical-site draws then observation draws, D4 transforms. Seed 20261024. AdamW learning rate 0.0005, weight decay 0.0001, float32, no AMP/TF32, gradient clip 1. Same v8 valid-pixel BCE positive weight 2 plus 0.1 pooled positive Dice. New model is trained once from scratch, checkpoints at 1,200/2,400/3,600/4,800. Thirty-minute fit cap. No extra seed, architecture or loss sweeps in this pass.

## Failure modes and preflight before the fit

- Reject source, protocol, manifest, prepared-array or schedule drift. Reject final/test entries before opening their arrays. Do not silently import an arm that builds the old model. New trainer filename must start with GTM_Model7_train_repaired for the frozen inference factory.
- Check all 958 TRAIN arrays during normal preparation, both real classes, band order, valid support, finite features, aligned D4 labels, no target/label channels in features and no DEV-based normalizer. Compare new feature tensors and pooled loss with unchanged v8. Invalid-pixel poisoning must not affect supported features or loss. Positive flags must agree with labels. Empty per-scene support and nonbinary support/labels must fail explicitly.
- Real TRAIN preflight: exact 100x100 output and finite logits; every architecture stage shape; nonzero finite encoder, decoder and head gradients; finite optimization update; deterministic seed initialization in two independently constructed models; changed weights after a real training update; fresh CPU checkpoint roundtrip within 1e-6. Record parameter count and a short real-batch timing estimate; stop on memory/numerical failure or if the measured time makes the cap impractical.
- Preflight source-bound receipt must precede training. Save exact draw schedule and compare with v8. Record all source/protocol/normalizer hashes, runtime versions and configuration. Old sources remain unchanged. No unit tests after implementation; exercise the real data-to-prediction path and save repeatable E2E artifacts.
- Fresh CPU process replays every saved DEV score map at all four milestones with probability error no more than 1e-6, identical support and exact native counts. Independently replay selected frozen inference before publishing. Stop on integrity failures.

## Scope limits

DEV has prior project exposure and selection use. No certifiably unused positive paired cached sites remain. Prior clear-only tests are consumed and must not be used to tune. Even a 70% DEV result cannot verify nationwide usefulness; independent positive and clear sites must be reserved before acquisition and checked later. No CAFO-presence labels as methane truth. These are binary MARS-S2L annotations, not quantitative NASA EMIT concentration reconstruction. No research-journal edits, external messages, commits, pushes or large downloads in this pass.
