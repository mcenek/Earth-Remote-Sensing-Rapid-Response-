# Model 7 same-site hard-negative follow-up, fixed before execution

The weight 2 and 3 Siamese models at learning rate `0.0005` and 1800 updates improve train/development scores, but train visual review still shows farmland-boundary activation and missed plumes. Only 10 of 120 train negatives share an exact `physical_location_id` with a positive train site. This experiment tests whether their under-sampling allows the model to use site appearance as a shortcut. The old held-out test remains excluded from all decisions.

Use the same frozen cohort, normalization, unchanged Siamese architecture, 48×48 crops, D4 transforms, optimizer, loss, threshold 0.5, and 1800-update budget. Generate the original fixed positive draws first and preserve them byte-for-byte. Replace negative draws with an independent seeded schedule: alternate a reviewed same-positive-site negative and a reviewed other-site negative. Sample a supported pixel to center each negative crop. Compare weight 2 and weight 3 under this same hard-negative schedule. Save schedule hash, source/manifest hashes, all checkpoint and full train/development probability hashes and confusion. Select using the predeclared rule of train recall at least 0.5, then maximum train IoU with development FPR as tie-breaker. If no arm clears the recall floor, mark failure. The final probabilities must be inspected as train/development diagnostics, not interpreted as unseen positive performance.

Failure checks: reject any split or hash mismatch, missing same-site or other-site negatives, changed positive draws, unsupported sampled pixels, populated output directory, nonfinite loss/gradient/probability, checkpoint mismatch, and fresh-process prediction mismatch beyond `1e-6`. Save an E2E receipt after replay. Never read test labels or earlier test predictions. Leave the original trainer and prior recovery runs unchanged.
