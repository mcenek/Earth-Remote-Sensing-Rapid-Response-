# GTM Model 7 sealed geographic confirmation protocol

This protocol was written before the confirmation exporter. The confirmation set is selected solely from the cached MARS-S2L official test **metadata**. The model configuration, training rule, checkpoint choice, preprocessing and probability cutoff must be frozen before any confirmation image, cloud, or label raster is opened. No official test raster was inspected to choose the rows below. The old 27-scene internal test has already been exposed and remains a diagnostic only.

## Failure cases to check before implementation

1. A proposed test row is absent from the official `test.csv` or the hash-pinned sealed-test metadata, or its label, source path, satellite, country, product level or coordinates disagree. Reject it. The sealed metadata's physical site name is a normalized producer identity and can differ from the UUID in `test.csv`; verify that UUID through the source filename and keep normalized sites together. Do not infer `NO_PLUME` from a missing mask.
2. A positive is within 100 km of **any** of the 203 old cohort observations, or shares any target/reference acquisition with the old cohort. Reject it. The 100 km rule was chosen from metadata for geographic independence before seeing recovery outputs.
3. A selected negative is not reviewed `NO_PLUME`, has producer observability other than `clear`, is within 100 km of any old scene, or shares a target/reference acquisition with any old scene. Reject it.
4. An image, cloud mask, or positive plume-mask path is missing according to a metadata-only file-existence check. Exclude it deterministically before selection. File existence does not establish TIFF validity.
5. A selected site is split between fitting, development and confirmation, or a target/reference acquisition leaks between those partitions. Fail. No old test scene may be reused in the new confirmation manifest.
6. A selected row is chosen, excluded, ordered or replaced based on model scores, cached predictions, label pixels, raster appearance, image quality derived from reading rasters, or the earlier exposed 27-scene diagnostic. Fail. Negative ordering is SHA-256 of the fixed seed and sample ID, with a cap of eight observations at each of the three positive sites.
7. Before configuration freeze, opening an official test image, cloud raster, plume raster or methane-enhancement raster is a protocol breach. After freeze, source identity, all grids, radiometry, cloud codes, binary labels and positive support must be checked using the same rules as the original temporal exporter. Record any quality exclusion; do not silently substitute a new test row.
8. A 20 m result is scored directly as if it were native 10 m truth, or confirmation data affects normalization, training, checkpoint choice, threshold or method selection. Fail. Repeat 20 m probabilities into 2 by 2 native blocks and score only supported 10 m pixels.

## Frozen metadata selection

Candidate pool: official `test.csv` rows present in `paper_v3_sealed_test_samples.jsonl`, US Sentinel-2 L1C. Three `PLUME` site groups farther than 100 km from every old scene meet the positive rule: Kansas `USA_pipeBV_Kansas`, Mississippi `USA_w7e8ngghj`, and Oklahoma `USA_hkth1ywhh`. Each uses one producer-reviewed positive observation. From each same physical site, select at most eight reviewed clear `NO_PLUME` observations that pass the geographic, acquisition and file-existence metadata filters. Sort eligible negative sample IDs by `sha256("20261023:" + sample_id)`, then take the first eight. Thus the maximum confirmation set is 3 positives and 24 negatives. Exact IDs, exclusions, source metadata hashes and candidate counts are recorded in `outputs/GTM_Model7_recovery_20261023/confirmation_selection.json` before raster access.

All three sites are unseen geographically by the two newly fitted temporal models and their 203-scene source cohort. Kansas has `test_only_site=false` in producer metadata, so it is **not** claimed to be untouched by all earlier project work. Mississippi and Oklahoma have `test_only_site=true`. These flags do not replace the explicit spatial and acquisition checks. The official test split will be consumed once, after the recovery configuration is frozen. Report the complete frozen result, including failed or excluded rows, without model-based replacement.

## Export and evaluation contract

After freeze, create a new manifest with the old train and dev arrays copied locally or safely referenced, and the old test removed. Export each confirmation row in the same `GTM_Model7_temporal_cohort_v1` array contract: six target and six reference bands in `B02, B03, B04, B08, B11, B12` order, 20 m 2 by 2 mean, clear and radiometrically valid support, 20 m target as the maximum native label over 2 by 2, and native 10 m label retained. Verify source files against the pinned release identities before decoding. Do not download data or use confirmation labels in fitting. The primary confirmation assessment uses the frozen final checkpoint and cutoff; exploratory diagnostics must be labelled separately.
