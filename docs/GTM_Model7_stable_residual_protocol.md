# Model 7 stabilized residual, train-only diagnostic protocol

This protocol and its failure checks precede `tools/GTM_Model7_stable_residual.py`. The original 12-channel residual model fails a four-real-training-crop ordinary BCE probe at learning rate 0.001, while the Siamese model fits the same crops. This diagnostic changes only the residual architecture: GroupNorm in its stem/blocks and residual branch scaling 0.1. It retains six normalized current bands plus six signed current-minus-reference bands, width 8, three blocks with dilations 1/2/4, the original 48-pixel seeded crop schedule, optimizer family, 0.50 cutoff and train-only normalization. It must never use old or new test labels, images or predictions.

## Failure cases and end-to-end checks fixed before implementation

1. Reject changed old manifest, source raster, array hash, split, support, band or label contract using the original validator with `labels=False` for test. Do not open a test label key, prediction, or new official-test raster. Load train/development arrays only for optimization and metrics.
2. A four-crop probe must use the exact first four old seeded train draws, saved as normalized current/reference arrays, target and support, with crop IDs/transforms and source hashes. Start at the original seed and train 300 identical updates using ordinary masked BCE, AdamW, learning rate 0.0005 and gradient cap 1.0. Save initial and final checkpoints, full or sampled loss/gradient trace, final four probability maps and confusion. Reject nonfinite loss, gradient or probability, changed crop data, and a probe that does not move parameters.
3. The probe qualifies only if positive-crop recall is at least 0.80 and negative-crop false-positive area below 0.05 at 0.50. If it fails, report failure and do not run full-scene training. Do not tune against old test results.
4. If qualified, train exactly 1,800 updates on the original seeded train schedule with learning rate 0.0005, positive weight 2, masked BCE plus 0.1 Dice, gradient cap 1.0. Use train labels and negative-only development labels. Save an initial checkpoint, final checkpoint, schedule hash, normalization, loss/gradient trace, and full train/development probability maps and metrics at 0.50. Do not select a checkpoint or threshold from the old test.
5. A fresh process must load the saved final checkpoint and reproduce saved train/development probabilities within 1e-6, plus confusion exactly. Record code, original trainer, protocol, manifest, input-crop and checkpoint SHA-256 hashes. The output receipt and probability files are the repeatable end-to-end artifact.
6. Stop at 15 minutes of training/probe wall time. A passing train/development result diagnoses learnability only; positive geographic transfer remains unknown until the separately frozen official confirmation evaluation.
